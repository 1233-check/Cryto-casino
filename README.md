# Crypto Casino

A modern, responsive crypto casino web application built with React, Vite, Tailwind CSS, PixiJS, and Framer Motion.

## 🚀 Features

- **Rich Game Library:**
  - **Crash:** Real-time multiplier graph with cashout mechanics.
  - **Dice:** Configurable win chance and multiplier slider.
  - **Mines:** Grid-based risk & reward minefield game.
  - **Limbo:** Target multiplier predictor.
  - **Color Trading:** Quick round prediction betting.
  - **Plinko:** Physics-inspired pegboard drop game with PixiJS.
  - **Tower:** Step-by-step risk ascension game.
  - **Hi-Lo:** Higher or lower card guessing.
  - **Wheel:** Spin-the-wheel prize multiplier game.
  - **Roulette:** Classic casino roulette wheel and betting table.
  - **Slots:** Animated multi-line slot reels.
  - **Blackjack:** Standard casino blackjack rules with dealer play.
  - **Baccarat:** Player, Banker, and Tie betting rounds.
  - **Video Poker:** Five-card draw poker gameplay.
- **Fair Play Architecture:** Includes provably fair utility algorithms.
- **Audio & Animations:** Integrated with Howler.js sound effects and Framer Motion transitions.

## 🛠 Tech Stack

- **Framework:** React 18
- **Build Tool:** Vite
- **Styling:** Tailwind CSS + PostCSS
- **Rendering & Physics:** PixiJS (v8)
- **Animation:** Framer Motion
- **Icons:** Lucide React
- **Sound:** Howler.js

## 📦 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn

### Installation

```bash
npm install
```

### Running Locally

To start the local development server:

```bash
npm run dev
```

### Building for Production

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
